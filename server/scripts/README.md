# Скрипты запуска (Windows)

- `run_api.ps1` / `run_api.bat` — запуск FastAPI.
- `run_collector.ps1` / `run_collector.bat` — запуск Telethon‑ингеста.
- `run_bot.ps1` / `run_bot.bat` — запуск Telegram‑бота управления.

Перед запуском убедитесь, что активировано виртуальное окружение и заполнен `.env`.
